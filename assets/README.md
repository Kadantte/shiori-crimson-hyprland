# Image licensing and asset status

Shiori's eligible original source code is MIT-licensed, but **not all images are**.

- [Original Kadantte artwork](ASSET-LICENSE.md): **free personal, non-commercial Shiori desktop use**; commercial use, resale, standalone republication, or public reuse in other projects requires prior written approval.
- [Google Chrome, Discord, Docker and other brand graphics](THIRD-PARTY-NOTICES.md): protected by **their respective owners' rights**. Official brand guidelines are linked; no automatic redistribution rights are granted.
- [Asset registry](ASSET-REGISTER.csv): lists only actual visual files approved for public distribution. The [third-party register](THIRD-PARTY-REGISTER.csv) lists currently withheld icons and any future reviewed material.

**No artwork is included in this starter/update kit.** The live Asura files `assets/shiori-menu-portrait.png`, `assets/shiori-reference-landscape.png`, `assets/album-fallback.png`, and local Chrome/Discord/Docker PNGs have not been supplied for provenance review, so must not be copied or published from this package.
