# Contributing

Shiori Crimson is a **public beta**. Please begin with an issue before substantial changes.

- Changes should be proposed as small, reviewable pull requests; never assume they should be applied to someone's live `~/.config`.
- Keep shell, Python and Hyprland changes portable; avoid assuming `DP-5`, `DP-6`, fixed home directories, or proprietary GPU settings.
- Document dependencies and a rollback path. Provide manual tests for both landscape and portrait launchers when relevant.
- **Do not add artwork, images, screenshots, logos, wallpapers or fonts** unless you own the rights and have explicit written permission to make them publicly available here. The owner reserves all rights in their images.
- Respect third-party licenses. Include author, source, license, required notices, and proof of redistribution permission for any external component.
- Never contribute API keys, passwords, tokens, private addresses, logs with sensitive metadata, SSH/GPG secrets, browser profiles, or raw machine snapshots.
- Code contributions are intended to be under MIT unless explicitly agreed otherwise; this does **not** grant any image reuse rights.

See [development safety policy](CLAUDE.md) and [licensing review](docs/licensing-review.md).
