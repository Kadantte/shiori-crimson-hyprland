# Security policy

This repository is a **beta**, and no published stable release is currently declared. There is no security-support guarantee.

Please avoid opening public issues with exploitable details, tokens, private filesystem paths, addresses, or secrets. If GitHub private vulnerability reporting is enabled for the repository, use that feature. Otherwise ask the maintainer for a private reporting channel without disclosing the vulnerability publicly.

Do not run or request unauthorized network scans, exploit demonstrations, or modifications to live user environments.
