# Third-party software components, dependencies, and license notices

No definitive dependency-license inventory is possible until the actual Shiori source archive is reviewed. Do not copy third-party source, bundle libraries, or select licenses on their behalf without identifying the exact upstream component and version.

For each dependency record: package/repository, version, license identifier and link, copyright holder, whether bundled or installed separately, license obligations, and verification date. Place required text in a `LICENSES/` directory only when copying it is allowed and appropriate.

**Brand icons are not software dependencies:** see [Third-party brand notices](../assets/THIRD-PARTY-NOTICES.md).
